# Intelliview 前端项目技术文档

## 1. 项目概述

Intelliview 是一个专注于为开发者提供高质量面试和笔试题目练习的 Web 应用平台。该项目采用前后端分离架构，前端基于 Vue 3 + TypeScript 技术栈开发，旨在为用户提供友好的界面和流畅的用户体验。

### 1.1 项目目标
- 为用户提供高质量的面试题目练习平台
- 为管理员提供便捷的题库和试卷管理功能
- 支持用户和管理员两种角色的权限管理
- 提供个性化的学习体验和数据统计

### 1.2 核心价值
- 简化面试准备流程，提高面试成功率
- 提供专业的题目管理和试卷生成功能
- 支持用户学习进度追踪和个性化推荐

## 3. 目录结构解析

### 3.1 整体目录结构

```
src/
├── components/         # 公共组件
│   ├── Footer/         # 页脚组件
│   └── Header/         # 头部组件
├── pages/              # 页面组件
│   ├── admin/          # 管理员端页面
│   │   ├── Auth/       # 管理员认证页面
│   │   ├── Home/       # 管理员首页
│   │   ├── Papers/     # 试卷管理页面
│   │   ├── Profile/    # 管理员个人中心
│   │   └── Questions/  # 题库管理页面
│   └── user/           # 用户端页面
│       ├── Login/      # 用户登录注册页面
│       ├── QuestionComponents/  # 题目相关组件
│       ├── Home.vue    # 用户首页
│       ├── Profile.vue # 用户个人中心
│       ├── QuestionBankDetail.vue # 题库详情页
│       └── QuestionDetail.vue # 题目详情页
├── router/             # 路由配置
│   └── index.ts        # 路由定义和权限控制
├── App.vue             # 应用根组件
└── main.ts             # 应用入口文件
```

### 3.2 目录结构说明

| 目录/文件 | 职责 | 说明 |
|----------|------|------|
| components/ | 公共组件 | 存放可复用的UI组件，如Header和Footer |
| pages/admin/ | 管理员端页面 | 包含管理员专属功能，如题库管理、试卷管理等 |
| pages/user/ | 用户端页面 | 包含用户使用的功能，如题目练习、个人中心等 |
| router/ | 路由配置 | 定义应用的路由结构和权限控制逻辑 |
| App.vue | 应用根组件 | 应用的主组件，包含全局布局和结构 |
| main.ts | 应用入口 | 应用的初始化文件，配置Vue实例和插件 |

## 4. 核心功能模块详细说明

### 4.1 认证模块

#### 4.1.1 登录功能
- **功能说明**：支持用户和管理员的登录验证
- **实现方式**：使用Element Plus表单组件，结合Vue的响应式数据和表单验证
- **权限控制**：根据用户名判断用户角色（用户名为"admin"时为管理员角色）
- **数据存储**：登录状态和用户信息存储在localStorage中
- **关键代码**：`src/pages/user/Login/LoginPage.vue`

#### 4.1.2 注册功能
- **功能说明**：支持新用户注册
- **实现方式**：使用Element Plus表单组件，包含用户名和密码验证
- **关键代码**：`src/pages/user/Login/RegisterPage.vue`

### 4.2 管理员端功能

#### 4.2.1 题库管理
- **功能说明**：管理员可以查看、添加、编辑和删除题目
- **实现方式**：使用Element Plus表格组件展示题目列表，支持分页和搜索
- **关键代码**：`src/pages/admin/Questions/index.vue`

#### 4.2.2 试卷管理
- **功能说明**：管理员可以创建、编辑和管理试卷
- **实现方式**：使用Element Plus组件构建试卷管理界面
- **关键代码**：`src/pages/admin/Papers/index.vue`

#### 4.2.3 个人中心
- **功能说明**：管理员可以查看和修改个人信息
- **实现方式**：使用Element Plus表单组件展示和编辑个人信息
- **关键代码**：`src/pages/admin/Profile/index.vue`

### 4.3 用户端功能

#### 4.3.1 首页
- **功能说明**：用户可以查看推荐题目和学习进度
- **实现方式**：使用Element Plus组件构建用户首页界面
- **关键代码**：`src/pages/user/Home.vue`

#### 4.3.2 题库详情
- **功能说明**：用户可以查看题库详情和包含的题目
- **实现方式**：使用Vue组件展示题库信息和题目列表
- **关键代码**：`src/pages/user/QuestionBankDetail.vue`

#### 4.3.3 题目详情
- **功能说明**：用户可以查看题目详情和提交答案
- **实现方式**：使用Vue组件展示题目内容和答案提交界面
- **关键代码**：`src/pages/user/QuestionDetail.vue`

#### 4.3.4 个人中心
- **功能说明**：用户可以查看和修改个人信息，查看学习记录
- **实现方式**：使用Element Plus组件构建个人中心界面
- **关键代码**：`src/pages/user/Profile.vue`

### 4.4 权限管理

#### 4.4.1 路由权限控制
- **功能说明**：根据用户角色控制路由访问权限
- **实现方式**：使用Vue Router的导航守卫，检查用户登录状态和角色
- **关键代码**：`src/router/index.ts`中的`router.beforeEach`钩子

#### 4.4.2 页面权限控制
- **功能说明**：根据用户角色动态展示页面内容
- **实现方式**：使用Vue的条件渲染，根据用户角色显示不同的导航菜单和功能
- **关键代码**：`src/components/Header/index.vue`中的角色判断逻辑

## 5. API接口文档

### 7.2 项目初始化

1. **克隆项目代码**
   ```bash
   git clone <项目仓库地址>
   cd frontend/Intelliview-frontend-web
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

   ```bash
   npm run build
   ```

   ```bash
   npm run preview
   ```

## 8. 部署流程

### 8.1 构建步骤

1. **安装依赖**
   ```bash
   npm install
   ```

2. **构建生产版本**
   ```bash
   npm run build
   ```
   构建完成后，生成的静态文件会放在 `dist` 目录中。

### 8.2 部署方式

#### 8.2.1 静态网站部署
- **适用场景**：小型应用，访问量不大
- **部署平台**：GitHub Pages、Vercel、Netlify等
- **部署步骤**：
  1. 将 `dist` 目录中的文件上传到静态网站托管服务
  2. 配置域名和SSL证书（可选）

#### 8.2.2 服务器部署
- **适用场景**：大型应用，需要更多自定义配置
- **部署平台**：Nginx、Apache等
- **部署步骤**：
  1. 将 `dist` 目录中的文件复制到服务器的Web根目录
  2. 配置Web服务器（如Nginx）的虚拟主机
  3. 启动Web服务器

### 8.3 部署注意事项

1. **环境变量配置**：根据部署环境配置相应的API地址和其他环境变量
2. **跨域配置**：确保后端API允许前端域名的跨域请求
3. **缓存策略**：配置适当的缓存策略，提高网站加载速度
4. **HTTPS配置**：生产环境建议使用HTTPS协议，确保数据传输安全

## 9. 常见问题解决方案

### 9.1 登录问题

#### 9.1.1 登录失败
- **问题描述**：输入正确的用户名和密码后登录失败
- **可能原因**：
  - 用户名或密码错误
  - 网络连接问题
  - 后端API服务异常
- **解决方案**：
  - 检查用户名和密码是否正确
  - 检查网络连接状态
  - 联系管理员检查后端服务状态

#### 9.1.2 角色权限错误
- **问题描述**：登录后无法访问预期的页面
- **可能原因**：
  - 用户角色配置错误
  - 路由权限控制逻辑问题
- **解决方案**：
  - 确认用户名是否正确（管理员用户名为"admin"）
  - 检查localStorage中的userRole值是否正确

### 9.2 页面访问问题

#### 9.2.1 404错误
- **问题描述**：访问页面时出现404错误
- **可能原因**：
  - 路由配置错误
  - 页面路径不存在
- **解决方案**：
  - 检查路由配置文件 `src/router/index.ts`
  - 确认访问的路径是否正确

#### 9.2.2 权限不足错误
- **问题描述**：访问页面时提示权限不足
- **可能原因**：
  - 用户角色与页面要求的角色不匹配
  - 登录状态已过期
- **解决方案**：
  - 确认用户角色是否正确
  - 重新登录以刷新登录状态

### 9.3 功能使用问题

#### 9.3.1 题目提交失败
- **问题描述**：提交题目答案时失败
- **可能原因**：
  - 网络连接问题
  - 表单验证失败
  - 后端API服务异常
- **解决方案**：
  - 检查网络连接状态
  - 确认表单填写是否完整
  - 联系管理员检查后端服务状态

#### 9.3.2 试卷创建失败
- **问题描述**：创建试卷时失败
- **可能原因**：
  - 表单验证失败
  - 题目选择不完整
  - 后端API服务异常
- **解决方案**：
  - 确认表单填写是否完整
  - 确认已选择足够的题目
  - 联系管理员检查后端服务状态

### 9.4 技术问题

#### 9.4.1 构建失败
- **问题描述**：执行 `npm run build` 时失败
- **可能原因**：
  - TypeScript类型错误
  - 代码语法错误
  - 依赖版本不兼容
- **解决方案**：
  - 检查TypeScript类型错误
  - 检查代码语法是否正确
  - 确保依赖版本兼容

#### 9.4.2 开发服务器启动失败
- **问题描述**：执行 `npm run dev` 时失败
- **可能原因**：
  - 端口被占用
  - 依赖安装不完整
  - 配置文件错误
- **解决方案**：
  - 检查端口是否被占用
  - 重新安装依赖 `npm install`
  - 检查配置文件是否正确
